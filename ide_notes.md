# Git в VS Code vs терминал

## Удобно в VS Code
1. Наглядный diff: изменения подсвечены построчно.
2. Встроенный редактор конфликтов (Accept Current / Incoming / Both).
3. GitLens показывает автора и дату каждой строки.

## Удобнее в терминале
- Interactive rebase, cherry-pick, reflog: полный контроль и работа на сервере по SSH.
