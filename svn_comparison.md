# Git vs SVN

1. Почему ветвление в Git «дешёвое», а в SVN «дорогое»?
В Git ветка — это лёгкий указатель на коммит (файл в ~40 байт), создаётся мгновенно.
В SVN ветка — копия директории на сервере, это медленнее и нагружает сервер.

2. Можно ли в SVN сделать коммит без интернета?
Нет. SVN централизованный: коммит идёт на центральный сервер, локально хранится
только рабочая копия. В Git коммиты локальные, отправляем push'ем позже.

3. Когда SVN может быть предпочтительнее?
Legacy-проекты (госсектор, банки), огромные бинарные файлы (игры, CAD),
централизованный контроль доступа к отдельным папкам, простота для нетехнических участников.
